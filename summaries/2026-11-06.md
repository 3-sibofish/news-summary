### 今日要点

**1. OpenAI 发布 GPT-6 Cyber：网络安全 agent 的能力与对齐双重突破**
OpenAI 推出专门用于网络安全的 GPT-6 Cyber，在 ExploitGym 上得分 48.5%（相对前代提升 51%），更关键的是在"蜜罐"测试中 99.93% 避免攻击范围外服务（加部署提示后 100%）。该模型已发现 81 个 Firefox 高危漏洞和 948 个 Linux 内核提权漏洞，且能生成补丁。这标志着 AI 安全研究从"能发现多少漏洞"转向"能否可控、对齐地行动"，对关键基础设施保护具有深远意义。

**2. Anthropic 自研 agent 级版本控制系统 Scion：当代码提交量从 2500/天暴涨至 30000/天**
Anthropic 用 5 个月将 monorepo 从 git 迁移至自研的 Scion，核心假设是"客户端永远在线"——这彻底颠覆了 git 的分布式离线设计。Scion 的 server 承担所有计算，客户端仅维护 bounded cache；changeset 替代 commit，支持水平扩展且无全局锁。这是首个为 agent 时代从零设计的 source control，预示着所有"为人类规模设计"的 dev infra（CI、build、review）都将被重构。

OpenAI 与学术社区合作发布三项 AI 发现的成果：证明 Sogge 局部光滑猜想（蕴含所有维度的 Kakeya 猜想和 Stein 限制猜想）、推翻广泛相信的 Exponential Time Hypothesis（ETH，3-SAT 可在 2^O(n/√log n) 时间内解决）、以及量子场论存在性证明。ETH 的反证已由 Russell Impagliazzo 等原始提出者领导的团队验证，并公开 Lean 形式化证明。这不仅是技术突破，更实验了三种不同的"AI 发现→人类理解"协作模式。

**5. Cursor、Devin、GitHub Copilot 同步推进"agent 定义即代码"基础设施**

#### Anthropic Engineering Blog

**Redesigning source control at Anthropic**

**核心论点**：Anthropic 因 Claude 导致代码提交量 4 个月增长 12 倍（2500→30000/天），git 作为为人类设计的分布式系统成为瓶颈，因此 5 个月内自研并全量迁移至 Scion——首个为 agent 时代设计的中心化版本控制系统。

**关键要点**：
- **规模压力**：main branch 历史近 100GB，工作副本 25GB+，日均 2500 万次 checkout（裸流量超 600PB/天），曾运行数百个 git mirror 仍难以为继
- **核心设计原则**：客户端永远在线（放弃离线完整副本）、client-server 不对称（server 承担所有计算）、全面水平扩展（无全量 materialized copy）、changeset 廉价增量无锁、工作副本稀疏化/虚拟化
- **Scion 数据结构**：changeset 作为 write-ahead log 条目，存储文件变更列表而非完整 tree pointer；支持 API 优先的查询模式，CI job 无需本地 repo 即可获取 diff/blame
- **迁移策略**：5 个月完成全 monorepo 迁移，同期构建 Antique（code review）、code search、IAM 等配套系统
- **agent 悖论**："Claude 写代码的能力既是让我们陷入这个困境的原因，也是我们快速构建 Scion 的方式"

**值不值得深读**：强烈推荐。这是目前最详细的"agent 时代基础设施重构"案例，对预测未来 CI/build/review 系统的演进方向极具参考价值。

**核心论点**：Google Research 开发 AI-PPG-ACC-HTN 系统，首次实现无需袖带校准的消费级智能手表被动高血压检测，精度媲美 24 小时动态血压监测（ABPM）金标准。
