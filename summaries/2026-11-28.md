# 每日摘要 2026-11-28

### 今日要点

**1. Anthropic 发布黎曼猜想证明，引发"AI 数学证明"范式争议**
Anthropic 数学家 Levent Alpöge 宣称与 Claude 合作完成了黎曼猜想（及广义黎曼猜想）的证明，但仅发布了 1.3GB 的 Lean 代码而非人类可读的论文。几乎同时，数学家 Alessandro Masullo 发布了其 12 年工作的 940 页人类手写证明草稿。这一事件凸显了 AI 辅助数学发现的根本张力：AI 可能生成"可验证但不可理解"的证明，而人类数学的价值不仅在于正确性，更在于洞察力和可传递性。正如 Alpöge 所言，"Claude 在终点线附近远远超越了我——不，Claude 是飞翔、舞动、闪耀着越过终点线的"，但这种"超越"是否改变了数学知识的本质，尚无定论。

**2. OpenAI 首次系统披露对抗性蒸馏防御体系**
OpenAI 详细阐述了如何防范攻击者通过蒸馏复制其前沿模型能力并绕过安全护栏。关键数据：在内部自适应评估中，针对 GPT-6.2 Astra 的受保护推理提取攻击成功率从 54.0% 骤降至 0.2%。这反映了 frontier lab 安全策略的重大转变——从单纯依赖模型层面的拒绝行为，扩展到保护推理痕迹（chain-of-thought）、API 级跨会话隔离、以及针对协调化提取活动的调查反制。该文暗示蒸馏风险已从知识产权问题升级为国家安全级别的双重用途（cyber/bio）能力扩散问题。

**3. Google 将 Duplex 电话 AI 深度集成至 Gemini 的 Tasks 功能**
Duplex 从 2018 年的餐厅预订演示，演进为基于 Gemini 4 模型的通用任务执行代理，可直接代用户致电商家处理预约、询价等事务。技术演进经历了三个阶段：早期 RNN 的封闭域定制 → LaMDA 的混合生成-确定性架构 → 当前完全基于 Gemini 的统一多模态栈。关键设计原则包括：通话开场明确披露 AI 身份、商家可随时退出、无需任何软件安装。这标志着 voice agent 从"炫技演示"进入"基础设施级服务"的拐点，但也引发对 AI 冒充人类通话的伦理边界讨论。

**4. Cursor 扩展市场遭恶意篡改，供应链攻击暴露 IDE 生态脆弱性**
攻击者在 Cursor VS Code 扩展市场上传了伪造的 Anthropic Claude Code 扩展（版本 2.1.312/313），植入 SSH 后门和持久化机制。尽管因权限不足多数攻击未能完全生效，但此事件揭示了 AI 工具链的供应链风险：开发者对"官方市场"的信任假设、扩展自动更新机制的攻击面、以及 AI coding 工具日益成为高价值目标的趋势。Cursor 的响应包括全市场下架重建、密钥轮换和 IOC 公开，但行业层面缺乏跨 IDE 市场的统一签名验证标准。

**5. Hugging Face 验证"Harness Adapter"可大幅提升模型在特定 agent 框架上的效率**
通过为 Qwen3.8-27B 训练特定于 Pi、OpenCode、Hermes Agent 三个 harness 的 LoRA adapter，在保持或提升任务通过率的同时，token 消耗降低约 40-50%（如 Pi harness 从 2.9K 降至 1.5K tokens/task）。核心洞察：通用模型在特定 agent 框架上存在显著的"适配摩擦"，而 RL 微调的 adapter 可以让模型学会"更少思考、更少工具调用、一次做对"。更值得注意的是，三个 adapter 可合并为单一"super adapter"跨框架运行，这为开源生态的模型-框架协同优化提供了可复现的配方。

#### Anthropic Engineering Blog

**Building strong safety evaluations**
[https://www.anthropic.com/research/building-strong-safety-evaluations](https://www.anthropic.com/research/building-strong-safety-evaluations)

- **核心论点**：AI 安全声明的可靠性完全取决于其背后的评估（eval）质量，而构建好的安全评估需要借鉴心理学界的"可重复性危机"改革经验，包括预注册假设、改进测量方法和严格统计。

- **关键要点**：
  - 安全评估的核心问题是"给定特定输入，模型是否做了正确的事"，而非简单测量特定能力
  - 单纯用"拒绝率"（refusal rate）作为指标可能适得其反：对自杀危机的完全拒绝反而是失败，理想回应应包含共情引导和危机资源转介
  - Anthropic 采用多轮对话评估，以"appropriate response rate"替代拒绝率，由领域专家制定特定风险领域的评分标准（rubric）
  - 评估设计必须匹配研究问题：观察性设计用于理解模型行为，因果设计（如对比有无特定干预）用于验证干预效果
  - 构建团队需要方法专家（抽样、评分、分析）和领域专家（心理学家、生物学家、政治科学家）的共同参与
  - 网络安全评估需在隔离沙箱中运行，无互联网访问，并实时监控以防模型逃逸造成实际危害
  - 需同时测量对有害请求的合规率和对无害请求的过度拒绝率，避免安全训练损害模型实用性

- **值不值得深读**：值得。这是 frontier lab 首次系统公开其安全评估方法论，对任何需要构建或依赖 AI 安全评估的研究者和从业者都有直接参考价值，且对"拒绝即安全"的简单化思维提出了重要修正。

**The components of agent memory**
[https://www.anthropic.com/research/components-of-agent-memory](https://www.anthropic.com/research/components-of-agent-memory)

- **核心论点**：AI agent 的记忆系统可以借鉴人脑的海马体-新皮层分工，通过"在线标记显著事件"（类似海马体编码）和"离线反思重组"（类似睡眠中的记忆巩固，称为"dreaming"）来实现有效的长期知识积累。

- **关键要点**：
  - "Memory notes"是 Claude 在会话间持久保存的知识，区别于权重更新、上下文内学习和摘要压缩等其他学习机制
  - 记忆的本质是对未来需求的预测：agent 写下规则，是在预测该模式未来会再次相关
  - CL-Bench 1.0 基准测试显示，不同模型的"学习闭环"能力差异显著：Claude Sonnet 4.6 只能生成未验证的猜测，而 Claude Opus 5 能形成"规则+验证依据+陷阱警告"的完整闭环
  - Pokémon Red 游戏测试揭示关键差异：Sonnet 3.7 无差别记录所有信息（413 个文件），导致记忆持续过时且检索开销爆炸；Fable 5 仅记录策略、计划和验证规则（9 个文件），进度远超前者
  - 有效记忆的标准：记录"屏幕上读不到"的信息（策略、计划、验证规则），而非冗余的状态快照
  - Opus 5.5 通过保持精简的目标追踪和下一步记录，成功通关游戏

- **值不值得深读**：值得。这是目前最具体的 agent 记忆系统设计公开披露，对构建长期自主 agent 的工程师有直接实操价值，尤其是关于"什么值得记忆"的判断标准。

#### Anthropic Research

**Teaching AI to build scientific models**
[https://www.anthropic.com/research/teaching-ai-to-build-scientific-models](https://www.anthropic.com/research/teaching-ai-to-build-scientific-models)

- **核心论点**：科学建模的核心价值不在于拟合数据，而在于获得对真实系统的洞察——这需要三个步骤（构建模型、约束参数、解释意义），而 AI 目前在参数约束上进展最大，但在模型构建和解释环节仍需人类深度参与。

- **关键要点**：
  - 1951 年 Hodgkin-Huxley 模型的案例：他们通过手动计算发现需将某变量取四次方才能拟合数据，当时不知原因，但该猜测后来预测了钾离子通道的四聚体结构——"计算的目的是洞察，而非数字"
  - 单纯复现数据的模型不足够：无数模型可能同样拟合数据，关键在于区分"有效模型的共同特征"与"无效模型的差异特征"
  - 贝叶斯推断可给出所有合理参数组合的概率分布，而非单一最优解，但对复杂模型计算不可行
  - 仿真推断（Simulation-Based Inference, SBI）通过大量随机采样+神经网络逆映射解决此问题：只需能正向运行模型（参数入、数据出），无需计算似然函数
  - SBI 适用于甚至无法写成简洁方程的复杂现象（神经元网络、星系碰撞等）

- **值不值得深读**：值得。对科学计算和 AI for Science 研究者有深度启发，尤其强调"可拟合≠可理解"的方法论警示，以及 SBI 作为连接复杂仿真与统计推断的桥梁价值。

**AI for scientific discovery: How researchers use Claude**
[https://www.anthropic.com/research/how-researchers-use-claude](https://www.anthropic.com/research/how-researchers-use-claude)

- **核心论点**：通过隐私保护方法分析 20.7 万次 Claude 科研会话，发现科学家主要在 AI 能力最强的任务（数据分析、写作）使用 Claude，而在其认为最重要的任务（想法生成、数据收集）使用较少；若 AI 能自动化所有非物理研究工作，计算机科学等领域产出可能提升 15 倍，而实验科学提升 3-4 倍。

- **关键要点**：
  - 使用分布：数据分析占 Claude 会话约 1/3，Claude Code 会话近 1/2；写作次之；想法生成和数据收集使用最少
  - 领域差异：形式科学（计算机、数学、统计）使用率最高，健康和实验室物理科学最低
  - AI 能力匹配度：AI 最适合的前 20% 任务获得的 Claude 使用量是时间占比预测的 2-4 倍；最不适合的后 20%（多为物理工作）使用极少
  - 当前能力下，广泛采用可使部分领域研究产出翻倍；若完全自动化非物理工作，计算机科学/统计可达 15 倍，化学/生物学 3-4 倍
  - 约 40% 的活跃 AI 使用研究者预计 2030 年前 AI 模型可独立完成完整研究项目
  - 风险警示：减少人类监督可能导致危险或不伦理研究；可能重塑研究者职业体验和知识追求的意义感
  - 研究方法：分类器标记会话字段和任务，仅保留聚合标签，不提取研究内容细节

- **值不值得深读**：值得。这是目前最大规模的 AI 科研使用实证研究，对理解 AI 对科学发现的实际影响和瓶颈有重要数据支撑，但需注意其基于当前 Claude 使用模式的观察性限制。

**Combatting adversarial distillation**
[https://openai.com/index/combatting-adversarial-distillation](https://openai.com/index/combatting-adversarial-distillation)

- **核心论点**：对抗性蒸馏使攻击者能复制 frontier 模型能力并部署无同等安全护栏的副本，OpenAI 通过多层防御体系将 GPT-6.2 Astra 的受保护推理提取攻击成功率从 54% 降至 0.2%。

- **关键要点**：
  - 蒸馏风险在双重用途领域（网络/生物）尤为严重：防御性网络安全能力可迁移至攻击性用途
  - 受保护推理（chain-of-thought）是核心保护目标：包含最终答案省略的中间信息，对蒸馏训练价值极高
  - 内部研究显示：使用精确推理痕迹训练的学生模型在监督微调后普遍优于使用推理摘要的模型；强化学习后，高推理预算下痕迹训练仍领先，低预算下摘要训练反超
  - 两层防御：请求层（模型行为、分类器、API 控制限制提取）+ 活动层（识别协调化提取活动的模式）
  - GPT-6.2 新机制：推理与产生它的对话历史绑定，若早期消息被重写则丢弃后续推理；阻止旧模型家族读取新模型推理
  - 对检测到的未授权蒸馏活动，调查账户网络并执行政策处罚，与其他模型提供商共享入侵指标

- **值不值得深读**：值得。这是 OpenAI 首次系统披露蒸馏防御的技术细节，对理解 frontier AI 安全策略演进和供应链风险有重要参考价值。

**Can AI help scientists identify promising drug candidates?**
[https://openai.com/index/introducing-medchembench](https://openai.com/index/introducing-medchembench)

- **核心论点**：MedChemBench 评估 AI 在药物化学推理任务上的表现，GPT-6.2 Astra 在最高推理设置下获 84.5% 得分，但结构重建（95.4%）远强于化合物选择和数值预测（约 50%），显示 AI 辅助药物发现仍有显著局限。

- **关键要点**：
  - 药物化学核心挑战：改善分子某一属性常恶化另一属性（如活性增强但吸收性降低）
  - 基准含 99 个问题，源自 117 篇论文/专利，761 个不同分子结构
  - 四组件评估：分子结构重建、科学推理解释、排序与选择、属性预测
  - GPT-6 Astra 在最高共享设置（xhigh）下总分 83.3%，GPT-6.2 Astra 84.5%，GPT-5.6 Sol 仅 58.2%
  - 结构重建案例：含 18 原子环的分子，GPT-6 Astra 10/10 正确，GPT-5.6 Sol 和 Luna 全部失败（分别生成 15 原子环和两个断裂片段）
  - 重要局限：无法排除模型在训练时见过相关文献；单次尝试无工具/反馈；评估历史推理而非真实药物发现

- **值不值得深读**：值得。对 AI for Science 和药物化学交叉领域有具体评估数据，且诚实披露了基准局限性。
