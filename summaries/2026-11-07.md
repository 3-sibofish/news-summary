#### Anthropic Engineering Blog

**Agent Memory 的组成要素**

**核心论点**：Agent memory 应采用类似人脑的分工机制——在线捕获事件、离线通过" dreaming "重组巩固，且记忆的本质是"对未来需求的预测"。

**关键要点**：
- 类比人类海马体（快速形成记忆）和新皮层（长期知识存储），提出"睡眠计算"（sleep-time compute）让 agent 在空闲时反思日志
- CL-Bench 1.0 测试显示模型代际进步：Sonnet 4.6 仅能生成未验证的猜测 → Opus 4.7 整合为参考文档并标记确认状态 → Sonnet 5 自动标记答案正确性 → **Opus 5 首次形成完整学习闭环**（规则+验证依据+陷阱警告）
- Pokémon Red 测试揭示关键差异：Sonnet 3.7 写入 413 个文件（记录所有细节，持续过时）仅获 1 枚徽章；**Fable 5 仅用 9 个文件+ global.md 仪表盘，记录策略/计划/验证规则，获 4 枚徽章**
- Fable 5 的关键洞察：屏幕可直接读取的信息（金钱、位置）无需记忆；只有 agent 自己推导出的策略、计划和验证规则才值得记录
- Opus 5.5 采用类似方法，最终通关游戏

**值不值得深读**：强烈推荐深读，这是目前最系统的 agent 记忆设计研究之一，对构建长期自主 agent 有直接指导意义。

[原文链接](https://www.anthropic.com/research/components-of-agent-memory)

#### Anthropic Research

**教 AI 构建科学模型**

**核心论点**：AI 辅助科学建模的关键不在于拟合数据，而在于理解"为什么这个模型有效而简单的版本不行"——即模型的解释力和可泛化性。

**关键要点**：
- 以 1951 年 Hodgkin-Huxley 模型为例：其四幂次项在数十年后被证实预测了钾离子通道的四亚基结构
- 科学建模三步循环：构建模型（决定方程形式）→ 约束模型（拟合参数）→ 解释模型（推断真实系统特性）
- 传统方法（如标准贝叶斯推断）对复杂模型计算不可行；**Simulation-Based Inference (SBI)** 通过大量模拟+神经网络克服此限制
- 关键洞见：仅给出拟合数据的模型不够，必须能区分"有效模型的共同特征"和"无效模型的差异特征"

**值不值得深读**：值得深读，尤其对 AI4Science 研究者，它澄清了"预测"与"理解"的根本区别。
