# 每日摘要 2026-11-25

### 今日要点

**1. Anthropic 开源 FlashProve：让 LLM 推理可密码学验证**
Anthropic 发布了 FlashProve 系统，首次让 400B 参数的 Llama 4 Maverick 模型能以约 110 tokens/秒的速度生成 zkSNARK 证明，证明开销仅为模型本身运行时间的 70-95 倍——比此前开源系统快数个数量级。这意味着用户无需信任模型提供商，可密码学验证"某个响应确实来自某个特定模型"，同时保护模型权重隐私。配合 Lean 形式化验证顶层安全保证，这是向"可证明 AI"基础设施迈出的关键一步，对模型审计、合规监管和防止路由欺诈都有深远意义。

**2. OpenAI GPT-6 展现蛋白质设计的"涌现"能力**
OpenAI 发布预印本显示，GPT-6 家族无需调用专用生物模型，仅凭推理和通用编程工具就能设计新蛋白质结构和序列。在湿实验室验证中，GPT-6.2 设计的 minibinder 在 5 个靶点上均观察到结合活性，重新设计的抗体也保留了结合能力。这标志着通用 LLM 开始侵入传统上需要专用科学模型的领域，"一个模型做所有事"的愿景在科学发现场景下取得实质性进展。

**3. Google DeepMind Gemini 4 Carbon 全面发布，定位"极限智能"任务**
Carbon 作为 Gemini 4 系列最强模型正式发布，专攻复杂多步编码、调试、开放式科学研究和网络安全。在 CursorBench 4.0、WANDR 和 AutomationBench 上排名第一，成本却低于次优外部模型 2 倍以上。特别值得注意的是其网络安全能力：在内部扫描中实现 100% 召回率和 95% 精确率，帮助 Google Cloud 漏洞研究团队确认了两个高危 0-day 漏洞。配合 /swarm 多 agent 协调功能，Carbon 代表了 GDM 重返前沿实验室竞争的标志。

**4. Devin Bots 推出：从"任务执行"到"结果拥有"的范式跃迁**
Cognition 发布 Devin Bots，让持久化 agent 可以端到端拥有目标而非仅执行单任务。典型案例令人印象深刻：Android Bot 在 44 天内自主合并 1,134 个 PR、产出 34.4 万行 Kotlin 代码，人类工程师仅发送 183 条消息；Layout Bot 三周内合并 159 个 PR，将页面布局偏移减少 70%；游戏工作室场景下 20 个 Bot 让单人周 PR 量从 50 增至 1,900。这标志着 AI 辅助编程正从" copilot 模式"向"自主团队"演进。

**5. AlphaProof Code 首次形式化验证 Signal 协议实现**
Google DeepMind 的 AlphaProof Code 框架用 AI agent 在 4 周内完成了专家团队通常需要数年的工作：对 Signal 加密协议的实际代码进行数学证明，生成超过 600 万行 Lean 代码。这是首次有 AI 参与的形式化验证被用于广泛部署的加密协议，且验证深度直达编译后代码而非仅设计层面。更关键的是，系统能识别故意重新引入的真实 bug 并证明其不安全性，为关键基础设施的软件安全树立了新标杆。

- 发布 5 项开源产物：技术报告、协议规范（Claude 撰写）、可执行代码（C++ 快速验证器 + Lean 可证明正确验证器）、Lean 证明及交互式可视化工具
- 应用场景包括：防止路由服务偷偷替换模型、独立评估者验证被测模型真实性、检测 token 流篡改、AI 发展节奏监管的合规工具

**值不值得深读**：值得。这是 AI 可验证性领域的重要里程碑，技术细节扎实，且全部开源，对关心模型安全、审计和去信任基础设施的读者尤为关键。
