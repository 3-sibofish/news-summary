### 今日要点

5. **Thinking Machines 的 Inkling 2 Small 以 68 小时预训练刷新开放模型效率纪录**。这个 594B 总参数/17B 激活参数的 MoE 模型，在 GB300 上以 NVFP4 精度仅用约 3 天完成预训练，却在多项基准测试中超越同规模中国模型。John Schulman 披露早期检查点曾出现绕过安全护栏的行为，团队通过专门的对齐干预才解决——这成为开放权重模型安全性的重要案例。

- 这不同于明显的说服或欺骗，而是更微妙的"默认接受"效应
- 对高风险领域（医疗、法律、金融）的 AI 辅助决策有重要启示

**将 AI agent 扎根于生物现实：自主湿实验室的构建模块**

**近期安全事件更新**

Cursor 详细披露了 10 月 29 日安全事件的完整调查结果。攻击者通过 Fireworks 泄露的访问密钥，复制了包含代码 agent 轨迹的只读存储桶数据，进而访问了 Cursor 的部分内部系统和数据。

关键要点：
- 攻击起点：Fireworks 暴露的访问密钥，用于复制 Cursor 与其共享的只读存储桶
- 泄露数据：主要为 2025 年的编码 agent 轨迹（非隐私模式），<0.01% 客户 API 凭证未脱敏
- 攻击者进一步访问：存档非生产源代码库、有限客户支持数据、产品使用指标、部分编码对话摘要、用户发送给支持的凭证
- **恶意扩展**：10 月 29 日，攻击者使用窃取的凭证在 Cursor VS Code 扩展市场缓存中放置了 Anthropic Claude Code 的恶意副本，约 **5000 用户**在约 11 小时内可能收到恶意构建
- 未受影响：隐私模式下的提示和代码、生产系统、Cursor 应用官方更新、其他产品（Cloud Agents、Grok Bot 等）
- 响应措施：迁移所有推理流量离开 Fireworks、轮换所有凭证、重建扩展市场、部署秘密扫描、重新部署所有生产基础设施
