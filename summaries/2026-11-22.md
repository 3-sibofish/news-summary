#### Anthropic Research

**How AI agents shape experts' judgment calls**

**核心论点**：当 AI agent 参与需要判断的决策时，专家会无意识地被 agent 的偏好引导，且缺乏元认知意识。

**关键要点**：
- 实验设计：50 名专业统计分析师使用 Claude Code 进行分析，每个关键决策点被随机分配两种合理选项之一作为 agent 的偏好
- 核心发现：分析师"大多跟随 agent 的倾向"，但事后"很少有人将 agent 列为原因"
- 隐含风险：即使存在多个可辩护答案的"判断型决策"，人类专家也会将自主性让渡给 AI
- 对"人类在环"（human-in-the-loop）治理框架的质疑：形式上的最终决策权不等于实质上的独立判断

**值不值得深读**：值得。这是首批直接测量自动化偏见在专家群体中效应的受控实验，对 AI 安全治理和产品设计有直接影响。

https://www.anthropic.com/research/agents-judgment-calls

#### Google Research Blog

**The sleep framework: A new way for LLMs to retain knowledge in continual learning**

**核心论点**：受人类睡眠记忆巩固启发，通过周期性"离线睡眠阶段"将 LLM 的短期上下文记忆转化为稳定长期参数，实现持续学习而不遗忘。

**关键要点**：
- 两阶段机制：NREM 式"记忆巩固"（知识蒸馏到低秩参数扩展的 MoE 块）+ REM 式"梦境"（随机专家激活生成合成训练样本，梯度过滤筛选高价值更新）
- 理论 grounding：记忆巩固是结构化低秩压缩问题，保留 on-policy 行为和语义奖励方向；梦境通过多样化梯度方向改善优化景观几何
- 实验结果：BABILong 1000 万 token 近完美扩展；Manchu/Kalamang 连续翻译零遗忘；AIME 24/25 达 79.2%/69.0%；数学推理超越 GRPO 和自蒸馏基线
- 与现有方法对比：ICL 受限于上下文窗口，SFT 导致灾难性遗忘，Cartridges/SEAL 等折中方案在扩展性上不足

**值不值得深读**：值得。这是持续学习领域少有的兼具理论深度和实证规模的突破，可能改变 LLM 部署后的更新范式。

https://research.google/blog/the-sleep-framework-a-new-way-for-llms-to-retain-knowledge-in-continual-learning/

#### Hugging Face Blog

**XYBench: Helping with the problem behind the question**

**核心论点**：当前 LLM 擅长回答用户字面问题，但普遍不擅长识别用户请求背后的错误假设（XY 问题），XYBench 通过 8115 个真实问题暴露了这一关键差距。

**关键要点**：
- XY 问题定义：用户想做 X，假设 Y 是方法，只问如何实现 Y，而 Y 可能是错误路径
- 评估维度：实用解决方案（是否覆盖 X 和 Y）、实用强调（回答重心在哪）、误解识别（是否引导用户转向 X）
- 核心发现：所有测试模型（Claude Sonnet 4.6、GPT-5、Gemini 3.1 Pro、Qwen3.5-9B、DeepSeek-V4 Pro）都更倾向于回答字面请求 Y 而非真实目标 X；Stack Overflow 上仅 35-41% 回答以真实目标为焦点
- 反直觉结果：明确提供用户目标 X 后，Sonnet 4.6 的目标解决方案率从 59% 升至 67%，但误解识别率从 47% 降至 34%——知道目标不等于会主动纠正用户
- 判断 vs 生成差距：模型作为评判者选择目标导向答案的比例（71-84%）远高于作为生成者主动提供此类答案的比例（35-41%）
- 获奖：EMNLP 2026 Best Resource Paper

**值不值得深读**：值得。揭示了 LLM 作为"助手"而非"问答机"的核心能力缺口，对客服、编程支持、教育等场景的产品设计有直接指导意义。

#### Argmin Gravitas (Ben Recht)

**Frontiers in Making up People**

UC Berkeley 教授 Ben Recht 的研究生研讨课现场博客，主题"硅采样"（silicon sampling）——用 LLM 模拟人类进行社会科学研究。

**核心论点**：LLM 已通过图灵测试，但"能模拟人回答问题"不等于"能替代人进行有意义的测量"。预测（如选举结果）与测量（如公众意见）是根本不同的认识论活动。

**关键要点**：
- Pew Research 发现硅样本与真实样本存在差异，但"哪个更对"本身成问题
- Eva Vivalt 新研究显示 LLM 能准确预测 2026 年 AEA 注册 RCT 的结果——预测优秀，但测量/解释/构念效度存疑
- 核心悖论：LLM 能匹配调查条件概率，但"40 岁写博客的计算机科学教授"内部毫无多样性——这是 LLM 的问题还是输入问题？
- Recht 立场：硅采样可能是"AI 最擅长的事——迫使我们反思学科实践是否在问正确问题"

**值不值得深读**：值得。对 AI 社会科学应用的哲学基础进行了尖锐而深入的审视。

https://www.argmin.net/p/frontiers-in-making-up-people

**Off to the Races**

同课程前期内容，批判选举预测的信息娱乐本质。

**核心论点**：选举预测主要是"伪装成新闻的娱乐"，将政治体育化（赛马叙事）获取注意力，而非真正的科学测量。

**关键要点**：
- 预测模型基于"如果今天举行假想选举"的模糊心理聚合，而非可量化的实在
- 历史：Literary Digest 1936 年溃败 → Gallup 崛起 → Dewey 败给 Truman → Zogby 1990 年代称王后因"互动投票"失准被群起攻之 → Nate Silver 奥巴马后封神、特朗普后跌落
- Grimmer, Knox, Westwood 指出：总统选举数据太少，无法判定谁"最好"
- 预测者实际按"最近 track record"被评判，与章鱼选 FIFA 冠军同理

**值不值得深读**：较短，作为预测批判文献的一部分有参考价值。

https://www.argmin.net/p/off-to-the-races

#### No Priors

**Powering AI-Driven Drug Discovery with President of Isomorphic Labs Max Jaderberg**

**核心观点**：Isomorphic Labs 总裁 Max Jaderberg 阐述如何用 AI 平台化方法重构药物发现，从"经验试错"转向"计算预测理解"。

Jaderberg 背景：牛津计算机视觉 PhD（AlexNet 转折点），2014 年创视觉公司被 DeepMind 收购，参与 AlphaGo/AlphaStar 等"不可能问题"，2021 年联合创立 Isomorphic。核心诊断：制药业生产率持续下降（每种新药成本从数亿升至 15 亿美元，周期从 8-9 年延至 15 年），尽管知识爆炸、新 modalities 涌现，因为本质仍是"经验驱动的高维组合试错"。细胞是复杂混沌系统，分子设计是组合爆炸问题，有限时间金钱限制了可探索的解空间复杂度——"低垂果实已被摘完"。Isomorphic 的差异化：不是逐个项目 bespoke 科学，而是构建可累积学习的基础平台，使每次药物研发加深对疾病生物学和分子设计的核心理解，实现创新规模经济。Jaderberg 对 5 年后的期望：疾病生物学的预测理解实现阶跃式提升。招聘：AI 与药物发现/化学/生物的交叉领域人才稀缺，需要构建全新混合团队文化。

https://www.youtube.com/watch?v=IiKf3BgBezE
