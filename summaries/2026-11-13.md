#### GitHub Blog (AI)

**Build once, run on any agent: A practical guide to agent skills**

GitHub 提出 **Agent Skills** 标准化方案，通过版本化的 SKILL.md 文件捕获可重复任务指令，实现跨 agent 复用。

**核心论点**：agent 技能应该是"可版本化、可共享、环境无关"的标准化单元，而非锁死在单次聊天或个人头脑中的隐性知识。

**关键要点**：
- 技能结构：以 SKILL.md 为中心，定义 clear job、input、output，包含 frontmatter（名称、描述）和具体执行指令
- **Proof Agent 示例**：独立验证器检查 AI 生成代码，核心规则"self-verification is not verification"

- 技能 vs 应用边界：需要稳定接口、共享状态、审计追踪、长期控制或外部权限 enforcement 时，应构建应用而非技能

#### Hugging Face Blog

**LLMON: An LLM-Native Markup Language, now in Granite 4.1 3B and 8B**

Hugging Face 与 IBM 合作推出 **LLMON**（LLM Object Notation），一种专为因果语言模型设计的原生标记语言，从根本上解决 LLM 上下文结构模糊和 prompt injection 攻击问题。

**核心论点**：JSON 为 parser 设计而非为 LLM 设计，LLMON 用保留特殊 token 作为结构分隔符，使结构和内容使用词汇表的不同部分，实现指令/数据的显式分离和精确绑定。

**关键要点**：
- 核心机制：语义相干组件用有意义标签标记，包裹在保留特殊 token 分隔符中；数据模式（含嵌套）以因果 LLM 无歧义方式声明；唯一 ID 实现指令与数据 payload 的精确绑定
- **安全突破**：OPI benchmark 上，LLMON 模型相比最佳前沿模型减少 **47%** 攻击成功率，相比最佳开源模型减少 **95%**；部分 benchmark 攻击成功率**接近零**
- 能力保持：与 Granite 4.1 Instruct 模型相当的一般能力，不因安全增益牺牲性能
- 与 chat template 关系：不替代而是丰富——chat template 区分角色，LLMON 说明组件含义和关系
- 实用工具：JSON ↔ LLMON 无损转换器，Mellea 平台原生支持
- 预览模型：granite-4.1-3b-LLMON-preview 和 granite-4.1-8b-LLMON-preview

**值不值得深读**：非常值得，这是从底层协议层面重新思考 LLM 输入表示的重要尝试，对安全关键应用有深远影响。

https://huggingface.co/blog/ibm-granite/llmon-an-llm-native-markup-language-now-in-granite

**The Definitive Fine-Tuning Guide for 3D Generation Models**

Hugging Face 发布 TRELLIS.2 的 LoRA 微调完整指南和容器化方案，支持本地和 Hugging Face Jobs 运行。

**核心论点**：针对特定 3D 对象类别（如家具、鞋类）的 LoRA 微调可以修正通用模型的细节错误，且通过选择性冻结（仅微调结构相关组件）避免灾难性遗忘。

**关键要点**：
- 实验目标：用 GSO 数据集的 188 个鞋类对象改善 TRELLIS.2 的鞋底几何精度
- **关键设计**：仅向 sparse-structure flow DiT 和 shape flow DiT 添加 LoRA（控制形状），**冻结 texture flow DiT**（保持原有材质能力）
- 冻结原因：数据集仅有漫反射颜色贴图（含烘焙光照），缺乏训练 texture flow 所需的独立材质贴图；训练会导致灾难性遗忘
- 参数规模：约 **930 万** adapter 参数，sparse-structure flow 用 rank 8，shape flow 用 rank 16
- 性能提升：预训练模型鞋底常出错，微调后改善
- 基础设施：提供预处理容器和微调容器，含完整依赖

**值不值得深读**：适合需要定制 3D 生成模型的研究人员和工程师，特别是资源有限时想用 LoRA 替代全量微调的场景。

https://huggingface.co/blog/3d-lora-finetuning

**[AINews] LLMs can read & write neural network weights: "Weight Space Programming" cuts Autoresearch out of the RSI loop**

Latent Space 报道一项"怪兽级"发现：LLM 可直接读写更小型神经网络的权重，实现无需人类干预的模型改进。

**核心论点**：这相当于不查看源代码、直接观察编译后二进制文件的 1 和 0，就能判断其功能、一次性修复 bug、或在 50 步内沿通用方向改进——将递归自我改进（RSI）从"需要编写 PyTorch/JAX 代码和监控训练"的复杂流程，简化为直接的权重空间操作。

**关键要点**：
- 背景：Karpathy 8 个月前的"autoresearch"演示了智能模型通过实验集群自主训练模型
- 新突破：Alex Zhang 等人证明，让智能模型直接读写更 dumb 模型的权重即可实现类似效果
- 能力：1）判断权重功能；2）给定失败轨迹一次性修复 bug，或 50 步内通用改进；3）一次性从零编写完整网络权重，击败部分独立训练模型
- 独立复现已出现
- 当前限制：类似机械可解释性，目前仅能处理简单游戏和 RL 策略，尚未扩展到更高级任务
- 意义：RSI 能力从 0 到 1 的突破，因效率极高将立即被探索和利用

**值不值得深读**：值得，这是理解 AI 自我改进前沿的关键进展，尽管当前能力边界有限。

https://latent.space/p/ainews-llms-can-read-write-neural-network-weights-weight-space-programming-cuts-autoresearch-out-of/
